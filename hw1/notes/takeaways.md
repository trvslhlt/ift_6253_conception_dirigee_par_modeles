# Takeaways

## Technologies
- Xtext
    - framework for building textual DSLs. From a grammar it generates a parser, Ecore metamodel, and  Eclipse editor
- Xtend
    - Language that compiles to Java source. Used for the formatter, tests, and generator
- Ecore
    - EMF's metamodel language
- EMF (Eclipse Modeling Framework)
    - library and tooling around Ecore. Generates the Java classes for the metamodel
- OCL (Object Constraint Language)
    - language for constraints on a metamodel
- MWE2 (Modeling Workflow Engine)
    - workflow runner that drives Xtext's code generation
- Eclipse PDE / OSGi
    - plug-in tooling. Each project is a bundle with a `MANIFEST.MF`, and the Runtime Eclipse launch runs the DSL editor from those bundles
